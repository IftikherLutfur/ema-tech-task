# Next.js Landing Page UI

A **pixel-perfect Next.js landing page** UI design converted from a Figma prototype. Built with modern tools and practices for responsive, high-quality web experiences.

---

## Features

- **Fully Responsive:** Desktop, tablet, and mobile views supported.
- **Gradient:** Eye-pleasing soft transitions using Tailwind CSS.
- **Custom Styled UI:** Tailwind CSS for styling.
- **Pixel-Perfect Conversion:** Design faithfully converted from Figma to Next.js.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** Tailwind CSS.
- **Icons:** React Icons
- **Image Hosting:** Cloudinary
